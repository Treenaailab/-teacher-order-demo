01
公开仓库个人效率工具独立 HTML 页面

TREENA 每日行动与复盘

将每日计划、行动记录和复盘集中在一个个人工作台中，让工作与生活任务能够按日期组织、按优先级推进，并保留后续回顾所需的信息。

  • 日历视图、工作区与生活区，支持优先级管理。
  • 提供阅读模式、回收站及删除撤销。
  • 浏览器自动保存编辑，支持导出全部备份迁移记录。
  • 支持导入 AI 复盘 JSON，将外部生成的复盘结果纳入工作台。
  • 近期提交加入每日习惯与日历打卡，以及备份支持。
实践价值

把个人效率需求转化为可反复使用的工具，打通行动记录、AI 辅助复盘与历史回顾。

数据与使用方式

编辑保存在当前浏览器；通过备份迁移记录，浏览器编辑不会自动同步 GitHub。AI 复盘通过 JSON 导入。

02
公开仓库交互式网页演示HTML · CSS · JAVASCRIPT

家教订单浏览器

面向老师的家教机会浏览工具，将结构化订单转化为可搜索、可筛选的信息界面。老师可按区域、科目、老师类型、授课时间与时薪筛选机会，并复制完整订单信息用于后续沟通。

  • 支持组合筛选、订单池切换、分页与无结果提示。
  • 采用响应式布局，提供移动端筛选面板。
  • 支持剪贴板复制及手动复制回退，展示区域与科目统计。
  • 另有面向家长与老师的公开服务指南，包含规范链接元数据、结构化数据与站点地图。
与 AI Agent 岗位的关联

结构化订单字段适合用于讲解自然语言意图提取、工具参数设计与可解释匹配。

后续可扩展方向

增加一个助手，将老师的自然语言偏好转为筛选条件，并解释推荐理由；订单是否可接及最终对接安排仍需确认。

当前边界：本次核查到的是浏览器演示页面，尚不能据此认定已有上线的智能匹配 Agent 或生产后端。

03
私有仓库 · 需访问权限业务流程管理NEXT.JS · PRISMA

TrademarkFlow 商标管理系统

根据仓库文档，这是一个使用 Next.js 实现的商标案件管理应用，将领域逻辑与存储适配分开组织，在统一界面中呈现案件阶段、进度、风险、优先级、负责人及下一步行动。

  • 总览仪表盘展示 7 项动态 KPI 与 P0/P1 优先事项。
  • 支持案件搜索与详情查看，展示阶段持续时间、剩余天数、风险原因、付款与证书状态。
  • 进度、风险与优先级由领域层统一计算，UI 和 API 消费计算结果。
  • 默认使用本地 JSON 持久化，幂等初始化 8 个演示案例；通过仓储接口与 Prisma/PostgreSQL 适配器支持后续切换存储。
与 AI Agent 岗位的关联

明确的业务规则与仓储边界，为受控工具访问、可追溯建议和业务数据查询提供基础。

后续可扩展方向

增加只读案件助手，检索当前记录、解释优先级，并提出交由人工确认的下一步建议。

私有仓库 · 需访问权限可复用 AI 技能指令设计

内容写作技能库

gongzhonghao-SKILL 仓库中已核查到 literary-philosopher 技能：一套用于文学哲思型写作的可复用指令，明确规定何时触发、如何组织论证，以及如何自检结果。

  • 定义任务路由的触发条件与排除场景。
  • 规定分阶段写作流程：识别真实问题、提出判断、选取典故、展开论证与收束。
  • 明确风格、篇幅与不同情境下的调整方式。
  • 要求避免虚构出处及过度引用，并提供输出前自检清单。
与 AI Agent 岗位的关联

展示如何把写作偏好转化为可复用的行为规范，并通过触发规则与质量约束控制输出。

后续可扩展方向

构建小型评估集，测试触发准确率、引用真实性、风格遵循，以及遇到排除任务时的表现。
