# 家教星球 V2.0

**版本日期：** 2026-10-02
**版本定位：** 现有家教星球项目的本地可运行版本；老师、家长、管理员通过同一系统和统一入口使用。
**数据状态：** 本机 SQLite 持久化；本版尚未部署到长期公网服务器。

## 1. 系统入口

| 角色/功能 | 页面 |
|---|---|
| 统一身份首页 | `/` |
| 老师订单浏览 | `/teacher` |
| 老师登记与资料 | `/teacher/register` |
| 家长师资浏览 | `/parent` |
| 家长提交需求 | `/parent/request` |
| 管理员账号密码登录 | `/auth` |
| 统一内部运营后台 | `/manage` |

## 2. 已纳入本版的业务能力

### 老师端

- 浏览已审核并公开的家教订单，按订单池、区域、科目、年级、老师类型、薪酬、时间及关键词筛选。
- 订单卡展示完整公开信息，支持分页、刷新和复制订单内容。
- 老师可登记资料；提交后进入审核流程，未审核资料不会出现在家长师资端。

### 家长端

- 按年级、科目等条件浏览已公开老师资料。
- 提交找老师需求；需求进入待审核状态，审核前不公开给老师。
- 老师和家长的电话、微信等联系信息按公开接口规则保护。

### 管理端

- 快速录单、渠道选择、批量粘贴解析、查重、草稿、人工修改及确认发布。
- 支持渠道A、渠道B、渠道C和自有渠道的订单文本解析；不同表达形式归一到标准订单字段，识别不确定或缺失的信息保留人工核对空间。
- 管理订单公开状态、业务状态、老师资料审核、家长需求审核、渠道配置和运营统计。
- 订单成交后建立财务记录，支持信息费调整、定金/收款/退款/渠道结算流水与分成查看。
- 管理员角色和操作权限由服务端会话控制；超级管理员具有额外的删除权限。

## 3. 数据与隐私

- 服务端数据库为 SQLite，默认路径 `data/tutor-v1.sqlite`，可通过 `TUTOR_DB_PATH` 改变。
- 原始订单、老师联系方式、运营记录属于业务数据，不进入 GitHub 源码仓库。
- 管理员密码只通过本机 `.env.local` 配置；公开仓库只保留不含值的 `.env.example`。
- 测试订单应使用虚构编号、虚构地址和虚构联系方式。
- 发布到服务器时，先备份本地 SQLite，再迁移到服务器持久磁盘，并核对订单、老师、家长需求、成交及流水数量后切换访问入口。

## 4. 代码结构

| 位置 | 内容 |
|---|---|
| `src/app` | Next.js 页面、后台路由及 API |
| `src/components/v1` | 老师、家长和管理端的业务界面组件 |
| `src/lib/parser.ts` | 多渠道订单拆分与字段解析 |
| `src/lib/v1/domain.ts` | 订单、权限与财务领域规则 |
| `src/lib/v1/store.ts` | SQLite 持久化及业务操作 |
| `miniprogram` | 老师端微信小程序离线浏览源码 |
| `scripts/export_miniprogram_snapshot.py` | 从本地业务库导出小程序公开数据快照 |
| `docs/数据库结构.sql` | 数据表与字段结构参考 |
| `tests` | 解析、业务规则和 HTTP 检查脚本 |

## 5. 本地启动与核验

需要 Node.js 22.13+ 和 pnpm。复制 `.env.example` 为 `.env.local`，填写两类管理员账号密码，然后运行：

```powershell
pnpm install
pnpm dev
```

默认访问 `http://localhost:3000/`。TypeScript 检查、构建及业务检查命令见 [README.md](README.md)。

## 6. 当前边界

- 这是本地运行版本；关闭运行服务后，本地网页不可访问。
- 目前没有固定公网域名、正式服务器部署或自动备份服务。
- SQLite 数据不会自动同步到其他电脑；团队共享需要后续部署到一台持久运行的服务器。
- 订单咨询、简历传递、试课沟通和收付款由运营人员在线下/微信承接；系统不直接连接或自动发送微信消息，也不处理在线支付。
- 解析结果需要人工复核后发布。订单文字格式超出已覆盖表达时，字段可能留空或需要修订。
- 测试凭据、真实业务数据库和订单原文不随版本文件发布。
- 小程序导出的 `miniprogram/data/snapshot.js` 含公开订单数据，属于生成文件；不会上传到公开仓库。重新生成前需先核对公开数据内容。

## 7. V2.0 验收重点

1. 统一首页进入老师、家长和管理员入口。
2. 老师端筛选、分页、刷新及复制完整订单。
3. 老师登记后审核，再由家长端查看脱敏资料。
4. 多渠道批量录单、修改解析字段、重复订单选择及确认发布。
5. 成交、收款、退款、渠道结算与收入计算流程。
